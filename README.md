# 1С: прикладные кейсы

Сборник решений на 1С:Предприятие 8.3 — автоматизация рутинных процессов учёта: обработки, расширения, интеграции.

Каждый кейс — отдельная папка с описанием задачи, документацией и исходниками модулей (`.bsl`).

## Кейсы

| Кейс | Что делает | Тип | Конфигурация | Статус |
|---|---|---|---|---|
| [egais-akt-spisaniya](egais-akt-spisaniya/) | Подготовка акта списания ЕГАИС: диагностика справок 2, исправление номенклатуры, статусов и соответствий акцизных марок, запрос марок, заполнение акта | Внешняя обработка | Розница 2.3 / УТ 11 (ЕГАИС) | MVP, в разработке |

## Структура кейса

```
<кейс>/
├─ README.md       — задача, решение, как собрать, статус
├─ CHANGELOG.md    — история версий
├─ src/            — исходники модулей (.bsl)
└─ docs/           — описание алгоритмов, структура объекта, тест-кейсы
```

Новый кейс — скопировать папку [`_template`](_template/) и заполнить.

## Общие правила

- **Исходники — в `.bsl`**, собранные `.epf` / `.cfe` в репозиторий не коммитим (прикладываются к Releases).
- **Никаких данных заказчиков:** выгрузок баз, реальных документов, марок, персональных данных, названий компаний и внутренних скриншотов.
- Имена объектов конкретной конфигурации, которые нужно сверить, помечаются `// УТОЧНИТЬ`.
- Тестирование — только на копиях баз.
