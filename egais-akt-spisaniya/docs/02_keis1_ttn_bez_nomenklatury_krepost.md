# 02. Кейс 1, часть 2: ТТН без номенклатуры и проверка крепости

Версия: 0.1. Зависит от: 00, 01.

---

## 1. Задача

**ТТН без номенклатуры.** Если в строке ТТН номенклатура не указана (или указана неверная) и шаги A/B из документа 01 не помогли, специалист идёт в основание ТТН — Поступление или Перемещение («суть не меняется»), находит там товар, копирует его в ТТН и проводит.

**Крепость.** Примечание со схемы: крепость номенклатуры иногда не совпадает с крепостью алкопродукции ЕГАИС (чаще у вина). Тогда крепость в номенклатуре меняют на ту, что в алкопродукции.

---

## 2. Изменения в адаптере

Добавить в `ИменаОбъектов()`:

```bsl
	// Как ТТН связана с документом поступления/перемещения. УТОЧНИТЬ
	// "РеквизитТТН"      — у ТТН есть реквизит со ссылкой на поступление/перемещение;
	// "РеквизитОснования" — у поступления/перемещения есть реквизит со ссылкой на ТТН.
	Имена.Вставить("ОснованиеТТН_Способ",   "РеквизитОснования"); // УТОЧНИТЬ
	Имена.Вставить("ТТНРеквизитОснования",  "ДокументОснование"); // УТОЧНИТЬ, нужен при способе "РеквизитТТН"
	
	// Крепость
	Имена.Вставить("НоменклатураКрепость",  "КрепостьАлкогольнойПродукции"); // УТОЧНИТЬ
	Имена.Вставить("АлкопродукцияКрепость", "Крепость");                     // УТОЧНИТЬ
```

Отдельная функция с описанием документов-оснований (в `ИменаОбъектов()` не кладём — там только строки):

```bsl

	Документы.Добавить(Новый Структура("ПолноеИмя, ТЧ, Номенклатура, Количество, СсылкаНаТТН",

	Документы.Добавить(Новый Структура("ПолноеИмя, ТЧ, Номенклатура, Количество, СсылкаНаТТН",
		"Документ.ПеремещениеТоваров", "Товары", "Номенклатура", "Количество", "ТТНЕГАИС"));
```

Документы, которых нет в конфигурации, резолвер пропускает — лишние записи не мешают.

|---|---|---|---|
| РазрешитьИзменениеНоменклатуры | Булево | Ложь | Защита: изменение карточки номенклатуры (крепость) только после согласования с заказчиком |

## 4. Алгоритм

### 4.1. ТТН без номенклатуры

1. Берём строки ТТН по справкам кейса 1, где номенклатура пустая **или** вид продукции номенклатуры ≠ вид алкопродукции.
2. **Резолвер основания** находит Поступление или Перемещение для ТТН.
3. Берём строки основания (номенклатура, количество) и оцениваем каждую как кандидата:

| Критерий | Баллы |
|---|---|
| Вид продукции (и объём, если включено) не совпадает | Кандидат отбрасывается |
| Номенклатура уже сопоставлена с этой алкопродукцией в регистре соответствий | +100 |
| Количество совпадает со строкой ТТН | +30 |
| Похожесть наименований (0…1) | +0…30 |

4. Решение:
   - лучший кандидат ≥ 40 баллов и отрыв от второго ≥ 20 — строка плана «Рекомендуется»;
   - иначе — строка плана с лучшим кандидатом и пометкой «Неоднозначно, проверьте / выберите вручную»;
   - кандидатов нет — строка «Информация».
5. Пользователь подтверждает или меняет номенклатуру кнопкой «Выбрать номенклатуру».
6. Действие — то же `ЗаполнениеНоменклатуры` из документа 01 (для неверной номенклатуры с `Заменить = Истина`).

### 4.2. Крепость

1. По **всем** справкам акта (не только кейсу 1) сравниваем крепость номенклатуры в строке ТТН и крепость алкопродукции.
2. Если номенклатура сопоставлена с алкопродукциями **разной** крепости — не меняем, строка «Информация»: нужна отдельная номенклатура.
3. Иначе — строка плана «ИзменениеКрепости» (одна на номенклатуру). Применяется только при `РазрешитьИзменениеНоменклатуры = Истина`.

```bsl
		Основание = ТТН[Имена.ТТНРеквизитОснования];
		Если ЗначениеЗаполнено(Основание) И ОписаниеДокументаОснования(Основание) <> Неопределено Тогда

			"ВЫБРАТЬ ПЕРВЫЕ 1
			|	Д.Ссылка КАК Ссылка

			|	%1 КАК Д
			|ГДЕ
			|	Д.%2 = &ТТН
			|	И НЕ Д.ПометкаУдаления", Описание.ПолноеИмя, Описание.СсылкаНаТТН));

		Если Описание.ПолноеИмя = ПолноеИмя Тогда
			Возврат Описание;
		КонецЕсли;
	КонецЦикла;
	Возврат Неопределено;

#КонецОбласти
```

```bsl
	|	Т.%3.Наименование КАК Наименование,
	|	Т.%3.#НоменклатураВидПродукции# КАК Вид,

	|ГДЕ
	|	Т.Ссылка = &Основание
	|
	|СГРУППИРОВАТЬ ПО
	|	Т.%3,
	|	Т.%3.Наименование,
	|	Т.%3.#НоменклатураВидПродукции#,

	Сопоставленные = НоменклатурыАлкопродукции(СтрокаТТН.Алкопродукция);

		Оценка = ОценкаКандидата(Кандидат, СтрокаТТН, Сопоставленные);
		Если Оценка < 0 Тогда
			Продолжить;
		КонецЕсли;
		НоваяСтрока = Кандидаты.Добавить();
		ЗаполнитьЗначенияСвойств(НоваяСтрока, Кандидат);
		НоваяСтрока.Оценка = Оценка;

Функция ОценкаКандидата(Кандидат, СтрокаТТН, Сопоставленные) Экспорт
	
	// Жёсткий фильтр: вид и (если включено) объём.
	Если ЗначениеЗаполнено(Кандидат.Вид) И ЗначениеЗаполнено(СтрокаТТН.Вид) И Кандидат.Вид <> СтрокаТТН.Вид Тогда
		Возврат -1;
	КонецЕсли;
	Если НастройкаПроверятьОбъем() И ЗначениеЗаполнено(Кандидат.Объем) И Кандидат.Объем <> СтрокаТТН.Объем Тогда
		Возврат -1;
	КонецЕсли;
	
	Оценка = 0;
	
	Если Сопоставленные.Получить(Кандидат.Номенклатура) <> Неопределено Тогда
		Оценка = Оценка + 100;
	КонецЕсли;
	
	Если Кандидат.Количество = СтрокаТТН.Количество Тогда
		Оценка = Оценка + 30;
	КонецЕсли;
	
	Оценка = Оценка + Окр(30 * ПохожестьНаименований(Кандидат.Наименование, СтрокаТТН.НаименованиеАлкопродукции));
	
	Возврат Оценка;
	
КонецФункции

// Номенклатуры, уже сопоставленные с алкопродукцией. Соответствие Номенклатура -> Истина.

	Пока Выборка.Следующий() Цикл
```

```bsl
// 0…1: доля общих значимых слов.
Функция ПохожестьНаименований(Знач А, Знач Б) Экспорт
	
	СловаА = ЗначимыеСлова(А);
	СловаБ = ЗначимыеСлова(Б);
```

```bsl
#Область Кейс1_Крепость

		Возврат;
```

## 6. Изменения формы

- Флажок `Объект.РазрешитьИзменениеНоменклатуры`.
- Команда **«Выбрать номенклатуру»** над таблицей плана (используется также в документе 04):

```bsl
&НаКлиенте
Процедура ВыбратьНоменклатуру(Команда)
	
	ТекущиеДанные = Элементы.ПланИзменений.ТекущиеДанные;
	Если ТекущиеДанные = Неопределено Тогда
		Возврат;
	КонецЕсли;
	
	Если ТекущиеДанные.ТипДействия <> "ЗаполнениеНоменклатуры"
		И ТекущиеДанные.ТипДействия <> "СозданиеСоответствия" Тогда
		ПоказатьПредупреждение(, "Выбор номенклатуры доступен только для строк заполнения номенклатуры и создания соответствия.");
		Возврат;
	КонецЕсли;
	
	Оповещение = Новый ОписаниеОповещения("ВыбратьНоменклатуруЗавершение", ЭтотОбъект, ТекущиеДанные.ПолучитьИдентификатор());
	ОткрытьФорму("Справочник.Номенклатура.ФормаВыбора", // УТОЧНИТЬ имя справочника
		Новый Структура("РежимВыбора", Истина), ЭтотОбъект, , , , Оповещение,
		РежимОткрытияОкнаФормы.БлокироватьОкноВладельца);
	
КонецПроцедуры

&НаКлиенте
Процедура ВыбратьНоменклатуруЗавершение(Результат, Идентификатор) Экспорт
	
	Если Результат = Неопределено Тогда
		Возврат;
	КонецЕсли;
	УстановитьНоменклатуруВСтрокеПлана(Идентификатор, Результат);
	
КонецПроцедуры

&НаСервере
Процедура УстановитьНоменклатуруВСтрокеПлана(Идентификатор, Номенклатура)
	
	СтрокаПлана = Объект.ПланИзменений.НайтиПоИдентификатору(Идентификатор);
	
	П = ЗначениеИзСтрокиВнутр(СтрокаПлана.ПараметрыСтрокой);
	П.Вставить("Номенклатура", Номенклатура);
	
	СтрокаПлана.ПараметрыСтрокой = ЗначениеВСтрокуВнутр(П);
	СтрокаПлана.Стало = СтрШаблон("%1", Номенклатура);
	СтрокаПлана.Основание = "Выбрано вручную";
	СтрокаПлана.Подтверждено = Истина;
	
КонецПроцедуры
```

## 7. Тест-кейсы

| № | Подготовка | Ожидаемый результат |
|---|---|---|
| 1 | В строке ТТН нет номенклатуры, соответствия нет, в поступлении одна строка этого товара | Строка плана «Рекомендуется» с номенклатурой из поступления |
| 2 | То же, но основание — перемещение | Аналогично (проверка резолвера) |
| 3 | В поступлении две похожие позиции (одна водка 0,5 разных брендов) | Строка «Неоднозначно», выбор вручную работает |
| 4 | В строке ТТН вино вместо водки | Кандидат-вино отфильтрован, предлагается водка, `Заменить = Истина` |
| 5 | Основание ТТН не найдено | Строка «Информация» |
| 6 | Вино: крепость номенклатуры 11%, в ЕГАИС 12% | Строка «ИзменениеКрепости»; при выключенном флажке — понятная ошибка, при включённом — крепость изменена |
| 7 | Номенклатура сопоставлена с двумя алкопродукциями разной крепости | Строка «Информация», без изменения |
| 8 | Дубли артикулов (две номенклатуры с одинаковым наименованием) | Строка «Неоднозначно» |

## 8. Вопросы

**К 1С-разработчику:**
1. Как связаны ТТН и Поступление/Перемещение: реквизит в ТТН, реквизит в документе поступления, ввод на основании, отдельный регистр?
2. Где хранится крепость номенклатуры (реквизит, характеристика, связанный справочник)?
3. Есть ли в строках поступления алкопродукция или справка 2? Тогда сопоставление строк можно сделать точным, без оценки по баллам.

**К заказчику:**
1. Кто вправе менять крепость в карточке номенклатуры? Нужно ли согласование с бухгалтерией / ответственным за НСИ?
2. Всегда ли крепость берём из ЕГАИС, или бывают исключения?
3. Что делать, если одна номенклатура сопоставлена с продукцией разной крепости: создавать новую номенклатуру или решать вручную?
4. Встречается ли расхождение объёма (0,5 против 0,7)? Это другая номенклатура, а не исправление карточки.
