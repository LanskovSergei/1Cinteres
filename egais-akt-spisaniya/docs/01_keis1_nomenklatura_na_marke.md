# 01. Кейс 1, часть 1: номенклатура на акцизной марке

Версия: 0.1. Зависит от: 00 (каркас).

---

## 1. Задача

У марки пустая или неверная номенклатура (например, алкопродукция «Водка», а номенклатура — вино), поэтому марка не находится при заполнении акта.

Ручной процесс сейчас:
1. Открыть ТТН-основание марки. Если около времени в заголовке `*` — нажать «Провести и закрыть». В большинстве случаев этого хватает.
2. Если не помогло — найти нужную номенклатуру в этой же ТТН и вставить её в проблемную строку, провести.

Эта часть автоматизирует оба шага. Поиск в документе-основании ТТН и проверка крепости — в документе 02.

---

## 2. Ключевой момент: что значит `*`

Звёздочка в заголовке формы ТТН появляется, когда форма **при открытии сама дозаполнила данные** (обычно номенклатуру по регистру соответствий) и документ стал «модифицированным». «Провести и закрыть» сохраняет дозаполнение, при проведении марки получают номенклатуру.

Следствие: **простое `Записать(Проведение)` без формы может ничего не исправить** — логика дозаполнения живёт в модуле формы, а не объекта.

Поэтому в коде два варианта дозаполнения:
- **Вариант 1 (предпочтительный):** вызвать ту же типовую процедуру, что вызывает форма ТТН в `ПриСозданииНаСервере` / `ПриЧтенииНаСервере`. Найти её в Конфигураторе — первая задача по этому документу.
- **Вариант 2 (запасной, реализован ниже):** собственное дозаполнение по регистру соответствий — только там, где алкопродукции соответствует ровно одна номенклатура.

## 3. Изменения в адаптере

Добавить в `ИменаОбъектов()`:

```bsl
	// Строки ТТН
	Имена.Вставить("ТТНСправка2",        "Справка2");             // УТОЧНИТЬ: может называться СправкаБ / НомерСправки2
	Имена.Вставить("ТТНАлкопродукция",   "АлкогольнаяПродукция"); // УТОЧНИТЬ
	Имена.Вставить("ТТННоменклатура",    "Номенклатура");         // УТОЧНИТЬ
	Имена.Вставить("ТТНКоличество",      "Количество");           // УТОЧНИТЬ
	
	// Номенклатура и алкопродукция: поля для сравнения.
	// Значение может быть путём через точку, например "ВидАлкогольнойПродукции.Код".
	Имена.Вставить("ТаблицаНоменклатуры",       "Справочник.Номенклатура");  // УТОЧНИТЬ
	Имена.Вставить("НоменклатураВидПродукции",  "ВидАлкогольнойПродукции");  // УТОЧНИТЬ
	Имена.Вставить("АлкопродукцияВидПродукции", "ВидПродукции");             // УТОЧНИТЬ
	Имена.Вставить("НоменклатураОбъем",         "ОбъемДАЛ");                 // УТОЧНИТЬ: единицы (дал / литры)!
	Имена.Вставить("АлкопродукцияОбъем",        "Объем");                    // УТОЧНИТЬ
```

Важно: вид продукции у номенклатуры и у алкопродукции должен сравниваться «одинаковыми» значениями. Если у номенклатуры это ссылка на справочник видов, а у алкопродукции — строковый код, в адаптере указываем путь до кода с обеих сторон (например, `ВидАлкогольнойПродукции.Код` и `ВидПродукции.Код`).

Если объём хранится в разных единицах (дал у номенклатуры, литры у алкопродукции) — проверку объёма отключаем настройкой `НастройкаПроверятьОбъем()` до уточнения.

## 5. Алгоритм

**Детект** (дополняет диагностику каркаса):
- марка с заполненной алкопродукцией, у которой строка ТТН-основания (по той же справке 2):
  - без номенклатуры, **или**
  - вид продукции номенклатуры ≠ вид алкопродукции, **или**
  - (если включено) объём номенклатуры ≠ объём алкопродукции.
- Количество таких марок пишется в `Результаты.НеверныхНоменклатур`, классификация каркаса относит справку к кейсу 1.

**План:**
- **Шаг A:** для каждой ТТН-основания (один раз, даже если она закрывает несколько справок) — действие «Дозаполнить и перепровести».
- **Шаг B:** для строк ТТН без номенклатуры — если в этой же ТТН есть строка с той же алкопродукцией и заполненной номенклатурой (и такая номенклатура одна) — действие «Подставить номенклатуру из ТТН».
- Шаг B идёт в плане после шага A. Если шаг A уже заполнил строку той же номенклатурой — шаг B просто пропускается.
- Строки ТТН с **неверной** (не пустой) номенклатурой шаг B не трогает — ими занимается документ 02.

**После применения** — каркас автоматически запускает повторную диагностику.

### 6.4. Действия

Заменить в каркасе процедуру `ДействиеПерепровестиДокумент` и добавить новые:

```bsl
#Область Кейс1_Действия

Процедура ДействиеПерепровестиДокумент(ДокументСсылка, ПараметрыДействия = Неопределено)
	
	Если ДокументСсылка.Метаданные().ПолноеИмя() = ИменаОбъектов().ДокументТТН Тогда
		ПроверитьРазрешениеПроведенияТТН();
	КонецЕсли;
	
	ДокументОбъект = ДокументСсылка.ПолучитьОбъект();
	ДокументОбъект.Заблокировать();
	
	Если ПараметрыДействия <> Неопределено
		И ПараметрыДействия.Свойство("Дозаполнить")
		И ПараметрыДействия.Дозаполнить Тогда
		ДозаполнитьНоменклатуруТТН(ДокументОбъект);
	КонецЕсли;
	
	ДокументОбъект.Записать(РежимЗаписиДокумента.Проведение);
	
КонецПроцедуры

// Параметры: ТТН, НомерСтроки, Номенклатура, Заменить (Булево).
Процедура ДействиеЗаполнитьНоменклатуруТТН(П)
	
	ПроверитьРазрешениеПроведенияТТН();
	
	Если Не ЗначениеЗаполнено(П.Номенклатура) Тогда
		ВызватьИсключение "Номенклатура не выбрана.";
	КонецЕсли;
	
	Имена = ИменаОбъектов();
	ТТНОбъект = П.ТТН.ПолучитьОбъект();
	ТТНОбъект.Заблокировать();
	
	СтрокаТЧ = ТТНОбъект[Имена.ТЧТТН].Найти(П.НомерСтроки, "НомерСтроки");
	Если СтрокаТЧ = Неопределено Тогда
		ВызватьИсключение СтрШаблон("В ТТН %1 нет строки %2.", П.ТТН, П.НомерСтроки);
	КонецЕсли;
	
	ТекущаяНоменклатура = СтрокаТЧ[Имена.ТТННоменклатура];
	
	Если ТекущаяНоменклатура = П.Номенклатура Тогда
		Возврат; // уже заполнено (например, шагом A)
	КонецЕсли;
	
	Если ЗначениеЗаполнено(ТекущаяНоменклатура) И Не П.Заменить Тогда
		ВызватьИсключение СтрШаблон("Строка %1 уже заполнена номенклатурой «%2». Проверьте вручную.",
			П.НомерСтроки, ТекущаяНоменклатура);
	КонецЕсли;
	
	СтрокаТЧ[Имена.ТТННоменклатура] = П.Номенклатура;
	ТТНОбъект.Записать(РежимЗаписиДокумента.Проведение);
	
КонецПроцедуры

// ВАРИАНТ 1 (предпочтительный): подставить сюда вызов той же типовой процедуры,
// что вызывает форма ТТН при открытии. Найти в модуле формы ТТН
// (ПриСозданииНаСервере / ПриЧтенииНаСервере). УТОЧНИТЬ.
// Например: ИмяОбщегоМодуляЕГАИС.ЗаполнитьНоменклатуру...(ТТНОбъект);
//
// ВАРИАНТ 2 (запасной, ниже): собственное дозаполнение по регистру соответствий.
Процедура ДозаполнитьНоменклатуруТТН(ТТНОбъект)
	
	Имена = ИменаОбъектов();
	ТЧ = ТТНОбъект[Имена.ТЧТТН];
	
	Алкопродукции = Новый Массив;
	Для Каждого СтрокаТЧ Из ТЧ Цикл
		Если Не ЗначениеЗаполнено(СтрокаТЧ[Имена.ТТННоменклатура])
			И ЗначениеЗаполнено(СтрокаТЧ[Имена.ТТНАлкопродукция]) Тогда
			Алкопродукции.Добавить(СтрокаТЧ[Имена.ТТНАлкопродукция]);
		КонецЕсли;
	КонецЦикла;
	
	Если Алкопродукции.Количество() = 0 Тогда
		Возврат;
	КонецЕсли;
	
	Карта = ОднозначныеСоответствия(Алкопродукции);
	
	Для Каждого СтрокаТЧ Из ТЧ Цикл
		Если Не ЗначениеЗаполнено(СтрокаТЧ[Имена.ТТННоменклатура]) Тогда
			Номенклатура = Карта.Получить(СтрокаТЧ[Имена.ТТНАлкопродукция]);
			Если Номенклатура <> Неопределено Тогда
				СтрокаТЧ[Имена.ТТННоменклатура] = Номенклатура;
			КонецЕсли;
		КонецЕсли;
	КонецЦикла;
	
КонецПроцедуры

// Соответствие Алкопродукция -> Номенклатура только там, где номенклатура ровно одна.
// Используется также в документе 04.
Функция ОднозначныеСоответствия(Алкопродукции) Экспорт
	
	Запрос = Новый Запрос(ПодготовитьТекстЗапроса(
	"ВЫБРАТЬ
	|	Соотв.#СоответствиеАлкопродукция# КАК Алкопродукция,
	|	МАКСИМУМ(Соотв.#СоответствиеНоменклатура#) КАК Номенклатура
	|ИЗ
	|	#РегистрСоответствий# КАК Соотв
	|ГДЕ
	|	Соотв.#СоответствиеАлкопродукция# В (&Алкопродукции)
	|
	|СГРУППИРОВАТЬ ПО
	|	Соотв.#СоответствиеАлкопродукция#
	|
	|ИМЕЮЩИЕ
	|	КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Соотв.#СоответствиеНоменклатура#) = 1"));
	Запрос.УстановитьПараметр("Алкопродукции", Алкопродукции);
	
	Карта = Новый Соответствие;
	Выборка = Запрос.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		Карта.Вставить(Выборка.Алкопродукция, Выборка.Номенклатура);
	КонецЦикла;
	
	Возврат Карта;
	
КонецФункции

#КонецОбласти
```

## 8. Тест-кейсы

Подготовить на копии базы:

| № | Подготовка | Ожидаемый результат |
|---|---|---|
| 1 | У марки очистить алкопродукцию | Диагностика: кейс 1 |
| 2 | В строке ТТН очистить номенклатуру, при этом соответствие для алкопродукции есть | Кейс 1; в плане шаг A; после применения справка «Готово» |
| 3 | Как 2, но соответствия нет, а в той же ТТН есть другая строка с той же алкопродукцией и номенклатурой | В плане шаги A и B; после применения — «Готово» |
| 4 | Как 3, но в ТТН две строки с одной алкопродукцией и разными номенклатурами | Строка «Информация», автозаполнения нет |
| 5 | В строке ТТН номенклатура вина при алкопродукции водки | Кейс 1; шаг B строку не трогает (её обработает документ 02) |
| 6 | Одна ТТН закрывает 3 проблемные справки | В плане одна строка шага A для этой ТТН |
| 7 | `РазрешитьПроведениеТТН = Ложь` | Действия с ТТН падают с понятной ошибкой, остальные строки плана применяются |
| 8 | ТТН в закрытом периоде | Ошибка в колонке «Результат» и в журнале, остальные строки применяются |
