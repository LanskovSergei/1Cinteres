# 07. Кейс 5: марки, отсканированные при инвентаризации

Версия: 0.1 — заготовка до получения образца файла.
Код: `src/ObjectModule.bsl` (v0.1.3), область `Кейс5_Инвентаризация`; форма — команды загрузки.

---

## 1. Задача

После инвентаризации сохраняется файл с акцизными марками, которые физически находятся в магазине. Их списывать не надо. Перед добавлением марок в акт нужно проверить, нет ли марки в этом файле: если есть — не списываем.

Файл в формате `.1ct`, его сохраняют сами после инвентаризации; к выгруженной базе он отношения не имеет.

## 2. Что сделано

- Табличная часть `ОтсканированныеМарки` (код марки) и реквизит `ФайлИнвентаризации`.
- Кнопка «Загрузить файл инвентаризации»: файл передаётся на сервер, читается как текст (UTF-8, при ошибках — windows-1251), из него выбираются коды марок.
- `КодыИнвентаризации()` возвращает загруженные коды. Их уже использует кейс 2: отсканированные марки не считаются «к списанию».

## 3. Что черновое

Разбор файла сделан без образца: текст режется по переводам строк, табуляции, `;`, `,` и кавычкам, кодами считаются фрагменты длиной от 68 символов (старые марки PDF417 — 68, новые DataMatrix — около 150). После получения примера `.1ct` разбор будет переписан точно.

## 4. Что ещё нужно
