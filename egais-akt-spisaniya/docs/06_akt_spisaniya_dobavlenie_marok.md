# 06. Акт списания: добавление марок и баг агрегации

Версия: 0.1. Зависит от: 00, 03 (`МаркиВСправочнике`).

---

## 1. Задача

Финальный общий шаг после всех кейсов (блок «Добавление в акт списания» на схеме):
- после того как марки готовы, их все копируют и добавляют в документ;
- перед этим удаляют строку справки, которую правили;
- **баг:** иногда с первого раза не добавляется — вместо 7 марок в одной строке появляется 7 строк по одной марке, подсвеченных красным; их удаляют и добавляют заново.

---

## 2. Ключевые моменты

**Не используем стандартный подбор.** Заполняем табличные части акта программно: одна строка товара на справку и все её марки с тем же ключом связи. Так баг «7 строк» не возникает в принципе.

**Идемпотентность.** Действие по справке всегда делает одно и то же: удаляет все строки этой справки с их марками и собирает заново. Повторный запуск даёт тот же результат, частично заполненный акт после ошибки исправляется повторным запуском.

**Какие справки перезаполнять.** По умолчанию — только исправленные в этом сеансе (как «удалить строку справки, которую правили» в ручном процессе). Настройкой можно перезаполнить все готовые.

**Акт не проводим и не отправляем.** Только записываем. Проведённый акт не трогаем — пользователь сначала отменяет проведение вручную.

**Разбор бага в типовой** — отдельная задача: понять причину полезно (возможно, это известная ошибка, которая лечится обновлением), но MVP от этого не зависит.

## 5. Алгоритм

1. **План:** для каждой справки из `Результаты` со статусом «Готово» (и, если включено, только из `ИсправленныеСправки`) — строка «ЗаполнениеСтрокиАкта».
2. **Действие по справке** (одна транзакция):
   1. Акт не проведён, иначе ошибка.
   2. Найти все строки товаров этой справки. Запомнить реквизиты первой как шаблон (номенклатура, алкопродукция и т.д.). Если строк нет — ошибка (справки нет в акте).
   3. Удалить эти строки товаров и все строки марок с их ключами связи.
   4. Получить марки справки в статусе «В наличии».
   5. Проверить: марок ровно столько, сколько было в строках акта. Иначе ошибка «сначала исправьте справку».
   6. Добавить одну строку товара по шаблону с новым ключом связи и количеством = число марок.
   7. Добавить строки марок с этим ключом.
   8. Проверить акт целиком (см. 6.3). Записать без проведения.
3. **Кнопка «Проверить акт»** — отдельная проверка без изменений: одна справка = одна строка, количество = число марок, нет дублей марок, нет «висящих» марок без строки товара.

### 6.2. Действие

```bsl
#Область Акт_Заполнение

// Параметры: Справка2.
Процедура ДействиеЗаполнитьСтрокуАкта(П)
	
	Имена = ИменаОбъектов();
	
	АктОбъект = Акт.ПолучитьОбъект();
	АктОбъект.Заблокировать();
	
	Если АктОбъект.Проведен Тогда
		ВызватьИсключение "Акт проведён. Отмените проведение вручную и повторите.";
	КонецЕсли;
	
	Товары = АктОбъект[Имена.ТЧАктаТовары];
	МаркиАкта = АктОбъект[Имена.ТЧАктаМарки];
	
	// 1. Шаблон строки, ключи, количество — и удаление строк справки.
	СтрокиСправки = Товары.НайтиСтроки(Новый Структура(Имена.АктСправка2, П.Справка2));
	Если СтрокиСправки.Количество() = 0 Тогда
		ВызватьИсключение "Справки нет в акте.";
	КонецЕсли;
	
	Шаблон = Новый Структура;
	Для Каждого Колонка Из Товары.ВыгрузитьКолонки().Колонки Цикл
		Если Колонка.Имя <> "НомерСтроки" Тогда
			Шаблон.Вставить(Колонка.Имя, СтрокиСправки[0][Колонка.Имя]);
		КонецЕсли;
	КонецЦикла;
	
	КлючиСправки = Новый Массив;
	КоличествоВАкте = 0;
	Для Каждого СтрокаТовара Из СтрокиСправки Цикл
		КлючиСправки.Добавить(СтрокаТовара[Имена.АктТоварыКлючСвязи]);
		КоличествоВАкте = КоличествоВАкте + СтрокаТовара[Имена.АктКоличество];
		Товары.Удалить(СтрокаТовара);
	КонецЦикла;
	
	Для Индекс = -(МаркиАкта.Количество() - 1) По 0 Цикл // обход с конца
		СтрокаМарки = МаркиАкта[-Индекс];
		Если КлючиСправки.Найти(СтрокаМарки[Имена.АктМаркиКлючСвязи]) <> Неопределено Тогда
			МаркиАкта.Удалить(СтрокаМарки);
		КонецЕсли;
	КонецЦикла;
	
	// 2. Марки справки «В наличии».
	Марки = МаркиСправкиВНаличии(П.Справка2);
	Если Марки.Количество() <> КоличествоВАкте Тогда
		ВызватьИсключение СтрШаблон("В наличии %1 марок, в акте по справке %2. Сначала исправьте справку.",
			Марки.Количество(), КоличествоВАкте);
	КонецЕсли;
	
	// 3. Одна строка товара с новым ключом.
	НовыйКлюч = НовыйКлючСвязи(Товары, Имена.АктТоварыКлючСвязи);
	
	НоваяСтрока = Товары.Добавить();
	Для Каждого КлючЗначение Из Шаблон Цикл
		НоваяСтрока[КлючЗначение.Ключ] = КлючЗначение.Значение;
	КонецЦикла;
	НоваяСтрока[Имена.АктТоварыКлючСвязи] = НовыйКлюч;
	НоваяСтрока[Имена.АктКоличество] = Марки.Количество();
	
	// 4. Марки с тем же ключом.
	Для Каждого Марка Из Марки Цикл
		СтрокаМарки = МаркиАкта.Добавить();
		СтрокаМарки[Имена.АктМаркиКлючСвязи] = НовыйКлюч;
		СтрокаМарки[Имена.АктМаркиЗначение] = Марка;
	КонецЦикла;
	
	// 5. Проверка и запись без проведения.
	Ошибки = ОшибкиАкта(АктОбъект);
	Если Ошибки.Количество() > 0 Тогда
		ВызватьИсключение "Акт не прошёл проверку: " + СтрСоединить(Ошибки, "; ");
	КонецЕсли;
	
	АктОбъект.Записать(РежимЗаписиДокумента.Запись);
	
КонецПроцедуры

// Массив значений марок для ТЧ акта (ссылки или коды — по настройке).
Функция МаркиСправкиВНаличии(Справка2)
	
	ПолеЗначения = ?(НастройкаЗначениеМаркиВАкте() = "Ссылка" И МаркиВСправочнике(),
		"Марки.Ссылка", "Марки.#МаркаКод#");
	
	Текст =
	"ВЫБРАТЬ
	|	&ПолеЗначения КАК Значение
	|ИЗ
	|	#ТаблицаМарок# КАК Марки
	|ГДЕ
	|	Марки.#МаркаСправка2# = &Справка2
	|	И Марки.#МаркаСтатус# = &СтатусВНаличии";
	Текст = СтрЗаменить(Текст, "&ПолеЗначения", ПолеЗначения);
	
	Запрос = Новый Запрос(ПодготовитьТекстЗапроса(Текст));
	Запрос.УстановитьПараметр("Справка2", Справка2);
	Запрос.УстановитьПараметр("СтатусВНаличии", ЗначениеСтатуса("ВНаличии"));
	
	Возврат Запрос.Выполнить().Выгрузить().ВыгрузитьКолонку("Значение");
	
КонецФункции

Функция НовыйКлючСвязи(Товары, ИмяКлюча)
	
	ТипКлюча = НастройкаТипКлючаСвязи();
	
	Если ТипКлюча = "УникальныйИдентификатор" Тогда
		Возврат Новый УникальныйИдентификатор;
	ИначеЕсли ТипКлюча = "Строка" Тогда
		Возврат Строка(Новый УникальныйИдентификатор);
	КонецЕсли;
	
	Максимум = 0;
	Для Каждого СтрокаТовара Из Товары Цикл
		Максимум = Макс(Максимум, СтрокаТовара[ИмяКлюча]);
	КонецЦикла;
	Возврат Максимум + 1;
	
КонецФункции

#КонецОбласти
```

### 6.3. Проверка акта

```bsl
#Область Акт_Проверка

// Возвращает массив текстов ошибок. Пустой — акт в порядке.
Функция ОшибкиАкта(АктОбъект) Экспорт
	
	Имена = ИменаОбъектов();
	Товары = АктОбъект[Имена.ТЧАктаТовары];
	МаркиАкта = АктОбъект[Имена.ТЧАктаМарки];
	Ошибки = Новый Массив;
	
	// 1. Одна справка — одна строка.
	СтрокПоСправке = Новый Соответствие;
	КлючиТоваров = Новый Соответствие;
	Для Каждого СтрокаТовара Из Товары Цикл
		Справка2 = СтрокаТовара[Имена.АктСправка2];
		СтрокПоСправке.Вставить(Справка2, ?(СтрокПоСправке.Получить(Справка2) = Неопределено, 1, СтрокПоСправке.Получить(Справка2) + 1));
		КлючиТоваров.Вставить(СтрокаТовара[Имена.АктТоварыКлючСвязи], СтрокаТовара);
	КонецЦикла;
	Для Каждого КлючЗначение Из СтрокПоСправке Цикл
		Если КлючЗначение.Значение > 1 Тогда
			Ошибки.Добавить(СтрШаблон("Справка %1: строк в акте %2 (должна быть 1)", КлючЗначение.Ключ, КлючЗначение.Значение));
		КонецЕсли;
	КонецЦикла;
	
	// 2. Марки: без строки товара, дубли, количество.
	МарокПоКлючу = Новый Соответствие;
	ВсеМарки = Новый Соответствие;
	Для Каждого СтрокаМарки Из МаркиАкта Цикл
		
		Ключ = СтрокаМарки[Имена.АктМаркиКлючСвязи];
		Значение = СтрокаМарки[Имена.АктМаркиЗначение];
		
		Если КлючиТоваров.Получить(Ключ) = Неопределено Тогда
			Ошибки.Добавить(СтрШаблон("Марка %1 не привязана ни к одной строке товара", Значение));
		КонецЕсли;
		
		Если ВсеМарки.Получить(Значение) <> Неопределено Тогда
			Ошибки.Добавить(СтрШаблон("Марка %1 в акте дважды", Значение));
		КонецЕсли;
		ВсеМарки.Вставить(Значение, Истина);
		
		МарокПоКлючу.Вставить(Ключ, ?(МарокПоКлючу.Получить(Ключ) = Неопределено, 1, МарокПоКлючу.Получить(Ключ) + 1));
		
	КонецЦикла;
	
	Для Каждого КлючЗначение Из КлючиТоваров Цикл
		СтрокаТовара = КлючЗначение.Значение;
		Марок = ?(МарокПоКлючу.Получить(КлючЗначение.Ключ) = Неопределено, 0, МарокПоКлючу.Получить(КлючЗначение.Ключ));
		Если Марок <> СтрокаТовара[Имена.АктКоличество] Тогда
			Ошибки.Добавить(СтрШаблон("Справка %1: количество %2, марок %3",
				СтрокаТовара[Имена.АктСправка2], СтрокаТовара[Имена.АктКоличество], Марок));
		КонецЕсли;
	КонецЦикла;
	
	Возврат Ошибки;
	
КонецФункции

// Для кнопки «Проверить акт».
Функция ПроверитьАкт() Экспорт
	Возврат ОшибкиАкта(Акт.ПолучитьОбъект());
КонецФункции

#КонецОбласти
```

Примечание: проверка количества предполагает, что количество в строке акта — в штуках (бутылках). Если оно в декалитрах или другой единице — УТОЧНИТЬ и доработать.

## 8. Разбор бага «7 строк» в типовой (отдельная задача)

Не блокирует MVP, но полезно для заказчика и для этапа 2 (в расширении можно исправить типовую форму).

1. На копии базы воспроизвести: акт, справка с 7 марками одной номенклатуры, добавление марок стандартным способом (как в инструкции). Записать точные шаги и что выбирается.
2. В Конфигураторе найти обработчик команды добавления/подбора марок в форме акта и процедуру, которая раскладывает марки по строкам.
3. Проверить гипотезы:
   - марки добавляются до того, как у строки товара появился ключ связи → каждая марка создаёт свою строку;
   - строки группируются по полю, которое у марок отличается (например, пустая номенклатура у части марок → вернуться к кейсу 1);
   - поведение зависит от порядка действий пользователя (сначала товары, потом марки).
4. Поискать исправление в описаниях обновлений конфигурации и на форумах 1С (партнёрский форум, Инфостарт).
5. Результат: описание причины и вариант — «лечится обновлением», «лечится порядком действий» или «исправляем в расширении».

| 1 | Справка исправлена (кейсы 1–3), в акте строка без марок | После применения: 1 строка, N марок, «Проверить акт» — в порядке |
| 2 | Воспроизвести «7 строк по 1 марке» | После применения: 1 строка, 7 марок |
| 3 | Запустить действие дважды | Результат тот же, дублей нет |
| 4 | В наличии 6 марок, в акте 7 | Ошибка «сначала исправьте справку», акт не изменён |
| 5 | Акт проведён | Ошибка «отмените проведение» |
| 6 | Справки нет в акте | Ошибка «справки нет в акте» |
| 7 | `ПерезаполнятьТолькоИсправленные = Ложь` | В плане все справки «Готово» |
| 8 | В акте марка без строки товара (испортить вручную) | «Проверить акт» показывает ошибку |
