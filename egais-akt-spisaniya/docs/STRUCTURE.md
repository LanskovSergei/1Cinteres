# Структура обработки «Помощник акта списания ЕГАИС»

Как собрать обработку в Конфигураторе и вставить код из `ObjectModule.bsl` и `FormModule.bsl`. Ориентировочно 30–40 минут.

Типы со ссылками на объекты конфигурации (`// УТОЧНИТЬ`) выбираются из того, что есть в базе: сначала демо-база Розницы 2.3, потом база заказчика.

---

## 1. Создание

1. Открыть базу в Конфигураторе → **Файл → Новый → Внешняя обработка**.
2. Имя: `ПомощникАктаЕГАИС`, синоним: «Помощник акта списания ЕГАИС».
3. Сохранить: `ПомощникАктаЕГАИС_v0.1.epf`.

## 5. Форма

### 5.2. Элементы формы

Имена элементов важны — код обращается к ним.

```
Форма
├─ ГруппаШапка (обычная группа, горизонтальная)
│   ├─ Объект.Акт
│   └─ Объект.ЛимитПакета
├─ ГруппаНастройки (обычная группа, сворачиваемая, заголовок «Разрешения»)
│   ├─ Объект.РазрешитьПроведениеТТН
│   ├─ Объект.РазрешитьИзменениеНоменклатуры
│   ├─ Объект.РазрешитьСменуСтатусов
│   ├─ Объект.РазрешитьПерепривязку
│   ├─ Объект.РазрешитьОтправкуЗапросов
│   └─ Объект.ПерезаполнятьТолькоИсправленные
└─ СтраницыФормы (группа «Страницы»)
    ├─ СтраницаДиагностика  — таблица «Результаты» (Объект.Результаты), только просмотр
    ├─ СтраницаПлан         — таблица «ПланИзменений» (Объект.ПланИзменений);
    │                         редактируется только колонка «Подтверждено»
    ├─ СтраницаСверка       — таблица «СверкаМарок» (Объект.СверкаМарок);
    │                         редактируются только колонки «СостояниеЕГАИС» и «ПоследнееДвижение»:
    │                         список выбора: значение «НаБалансе» с представлением «В обороте», значение «НеНаБалансе» с представлением «В архиве» (ручной резерв; обычно заполняется из остатков ЕГАИС),
    │                         событие ПриИзменении → СверкаМарокСостояниеЕГАИСПриИзменении,
    │                         «ПоследнееДвижение» — поле ввода, событие ПриИзменении → СверкаМарокПоследнееДвижениеПриИзменении
    ├─ СтраницаОчередь      — декорация-надпись «НадписьПрогноз»
    │                         + таблица «ОчередьЗапросов» (Объект.ОчередьЗапросов), только просмотр
    └─ СтраницаИнвентаризация — поле Объект.ФайлИнвентаризации (только просмотр)
                              + таблица «ОтсканированныеМарки» (Объект.ОтсканированныеМарки)
```

Имена таблиц на форме должны совпадать с именами табличных частей: `Результаты`, `ПланИзменений`, `СверкаМарок`, `ОчередьЗапросов` (так делает Конфигуратор по умолчанию при перетаскивании).

В таблице плана колонку `ПараметрыСтрокой` скрыть (служебная).

### 5.3. События формы

На вкладке «Элементы» → свойства формы → события:
- `ПриСозданииНаСервере` → `ПриСозданииНаСервере`
- `ПриОткрытии` → `ПриОткрытии`

### 5.4. Модуль формы

Вкладка «Модуль» → вставить `FormModule.bsl` целиком.

---

## 6. Проверка

1. **Модуль → Проверить синтаксис** (Ctrl+F7) в обоих модулях.
2. Сохранить (Ctrl+S).
3. Запустить базу в режиме 1С:Предприятие → **Файл → Открыть** → выбрать `.epf`.
4. Нажать **«Проверить адаптер»** → по списку расхождений править `ИменаОбъектов()`, `СоответствиеСтатусов()`, `ДокументыОснованияТТН()` в модуле объекта.
5. Выбрать акт → **«Диагностика»**.

Если синтаксис-контроль ругается на имя, которого нет в конфигурации, — это почти всегда тип реквизита обработки/ТЧ (раздел 2–3) или имя справочника в `ВыбратьНоменклатуру` модуля формы.
