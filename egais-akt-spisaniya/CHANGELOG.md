# Изменения

## 0.1.4
- Битые ссылки «<Объект не найден>»: справки с такими марками получают статус «Ручное решение» (лечится на сервере с синхронизацией), автоисправлений по ним нет.
- Контроль уникальности справки 2: если в базе есть марки нескольких организаций ЕГАИС по одной справке, диагностика останавливается.
- Остатки ЕГАИС читаются по последнему документу для каждой справки; режим «полный снимок» выключен по умолчанию — справки нет в остатках, значит данных нет.

## 0.1.3
- Кейс 2 по ответам 22.09: статусы ЕГАИС «В обороте» / «В архиве»; чтение последних полученных остатков через адаптер; без ограничения по возрасту остатков — вместо этого не трогаем марки, двигавшиеся в 1С после даты остатков; марки «есть в ЕГАИС, нет в 1С» ставятся в очередь запросов (кейс 4).
- Код устойчив к отсутствию значений перечисления статусов («В резерве» необязательный).
- Заготовка кейса 5: загрузка файла инвентаризации (.1ct), черновой разбор кодов марок, вычитание отсканированных марок в кейсе 2.

## 0.1.2

- Новые колонки диагностики: НеВЕГАИС, ВЕГАИСНеВНаличии, ДанныеЕГАИС; колонка сверки ВИнвентаризации (задел под кейс 5).
- Смена статусов включена по умолчанию.
