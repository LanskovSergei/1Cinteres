# API для 1С

Базовый адрес: `http://<сервер>:8000`. Если в `.env` задан `API_KEY`, каждый запрос должен нести заголовок `X-API-Key`.

## POST /v1/reconcile

Сверка по одной справке 2.

```json
{
  "reference": "FB-000008301033149",
  "marks": [
    {"code": "...", "status": "ВНаличии", "moved_at": "2026-09-01T10:00:00", "has_receipt": false}
  ],
  "egais": {"codes": ["..."], "quantity": null, "received_at": "2026-10-01T12:00:00"},
  "scanned_codes": ["..."],
  "inventory_loaded": true,
  "act_quantity": 1
}
```

`egais`: либо `codes` (ответ по регистру №3), либо `quantity` (регистр №1). Если нет ни того, ни другого — сервис вернёт замечание «нет данных ЕГАИС».

Ответ:

```json
{
  "reference": "FB-000008301033149",
  "case": 2,
  "data_source": "codes",
  "in_stock_1c": 10,
  "on_balance_egais": 11,
  "scanned": 10,
  "to_write_off": 1,
  "act_quantity": 1,
  "status_changes": [
    {"code": "...", "old_status": "Реализована", "new_status": "ВНаличии",
     "reason": "ЕГАИС: В обороте", "confirmed_by_egais": true}
  ],
  "issues": [],
  "elapsed_ms": 1.2,
  "marks_processed": 11
}
```

`confirmed_by_egais: false` означает, что марка подобрана по недостаче количества, без подтверждения ЕГАИС: такие строки в 1С не отмечаются автоматически.

## POST /v1/inventory/parse

```json
{"content": "<текст файла .1ct>"}
```

Возвращает нормализованные коды марок и их количество.

## POST /v1/nomenclature/match

```json
{
  "alcohol_name": "Водка ГОРНОЕ ОЗЕРО",
  "alcohol_kind": "водка",
  "candidates": [
    {"id": "...", "name": "Водка ГОРНОЕ ОЗЕРО 0,5л", "already_linked": true, "source": "марки"}
  ]
}
```

Возвращает лучшего кандидата, признак `reliable` и пояснение. При `reliable: false` 1С не подставляет номенклатуру автоматически.

## GET /v1/metrics/summary

Сводка за день: сколько запросов и марок обработано, среднее время на марку, сколько ошибок. Это ответ на вопрос «сколько марок система обрабатывает за день».

## Коды ответов

| Код | Когда |
|---|---|
| 200 | Обработано |
| 401 | Неверный или отсутствующий `X-API-Key` |
| 422 | Тело запроса не соответствует контракту |
| 500 | Внутренняя ошибка, подробности в логах |
